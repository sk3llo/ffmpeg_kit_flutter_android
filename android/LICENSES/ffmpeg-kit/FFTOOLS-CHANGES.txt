FFmpegKit's fftools_*.c and fftools_*.h files are modified copies of the fftools
sources of FFmpeg (LGPL-2.1-or-later). Each file's header lists FFmpegKit's
changes up to 07.2023. Changes made since then, by date:

2025-06-09  (Android) fftools_ffmpeg_mux_init.c: compile fixes
2025-07-13  (Android) fftools_ffmpeg_mux_init.c: updated for FFmpeg 7.1.1
2025-10-09  (all) ported to FFmpeg 8.0
2026-06-28  (all) set the abuffersink all_channel_counts option through
            filter arguments (FFmpeg 8.x)
2026-07-28  (Linux) ported the FFmpeg 8.x fftools from the Windows copy;
            av_noreturn placed so C++ units compile
2026-10-30  (Android, Apple) apply -display_rotation, -display_hflip and
            -display_vflip; restore side_data_list for streams in ffprobe
2026-11-18  (all) video with no colour information is no longer tagged as RGB
