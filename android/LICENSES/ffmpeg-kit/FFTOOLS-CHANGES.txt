FFmpegKit's fftools/ files are modified copies of the fftools sources of
FFmpeg n9.1 (LGPL-2.1-or-later). They come from FFmpegKitNext
(https://github.com/arthenica/ffmpeg-kit-next, LGPL-3.0-or-later), whose
changes each file's header lists. Changes made in this repository, by date:

2026-11-20  (all) replaced with FFmpegKitNext's fftools
            (arthenica/ffmpeg-kit-next at d031df3, based on FFmpeg n9.0.2),
            merged with FFmpeg n9.1's fftools
2026-11-20  (Windows) prepare_app_arguments() keeps the arguments FFmpegKit
            passes instead of reading the host process's command line
